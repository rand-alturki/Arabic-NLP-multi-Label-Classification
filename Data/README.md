# Data

This project uses the **ADAB (Arabic Dataset for Automated Politeness Benchmarking)** dataset, released as part of the AdabEval 2026 Shared Task.

## Dataset Access

The dataset is described in the following paper:

> Al-Khalifa, H., Ghezaiel, N., Bounnit, M., Alhazmi, H., Alfear, N., Alqifari, R., Almasoud, A., & Al-Ghamdi, S. (2026).
> *ADAB: Arabic Dataset for Automated Politeness Benchmarking — A Large-Scale Resource for Computational Sociopragmatics.*
> https://doi.org/10.48550/arXiv.2602.13870

To obtain the data, visit the shared task page or the arXiv link above and follow the organizers' instructions for access.
